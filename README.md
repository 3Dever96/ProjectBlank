# Title

**Edge of Eternity**

## Description

*Edge of Eternity* is a 2D 8-bit "Mega-Metroidvania" about a young mercenary reclaiming his soul.  After being sacrificed by a greedy Noble seeking immortality, the hero's power and memories are shattered into four elemental fragments.

* **Gameplay:** Fight through a non-linear world to defeat four "Guardians"- splintered versions of yourself- to reclaim **Fire, Wind, Earth, and Ice** abilities.
* **Narrative:** Every boss defeated restores your memories and evolves your character's appearance from a featureless "blank" into a legendary warrior.
* **Goal:** Reach the point where eternity meets the physical world to defeat your own mindless "True Form" and the immortal Noble to stitch the fractured world back together.
* **Style:** High-energy shonen action met with strict NES-style 8-bit constraints for a focused, polished indie experience.

## Getting Started

These instructions will get you a copy of the project up and running on your local machine for development and testing purposes.

### Requirements

**Unity Hub**
**Unity Editor Version:** '6.4 Beta (6000.4.0b2)' (or minimum recommended patch version)
**Target Platform:** 'Windows' (Requires the Windows Build Support module installed via Unity Hub)

### Installation

1. **Clone the repository:** 
'''bash
git clone https://github.com/3Dever96/ProjectBlank.git
'''

2. **Open in Unity**
* Open **Unity Hub**.
* Click **"Add Project from Disk"**.
* Navigate to the cloned directory and select the root folder.
* Ensure the correct Unity Editor Version ('6.4 Beta (6000.4.0b2)') is selected in the Hub and open the project.

3. **Run the Project:**
* Once the Editor loads, navigate to the primary scene file (usually in 'Assets/Scenes/').
* Press the **Play** button in the Unity Editor to begin.
